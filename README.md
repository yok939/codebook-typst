# codebook-typst

ICPC codebook generator written in Typst, used by team **yokAndHisBuddies**.

## Building

Run ``typst c main.typ`` to build the PDF file.

## Editing 

The main source files include:
* ``config.yaml`` - YAML file for configuring file path.
* ``src/`` - Main source code reference directory.

To add or delete a specific source code from the codebook, just update the files in ``src/`` directory, and edit target file path to ``config.yaml``.

## Dependencies

* Typst 0.15.1 or newer
